MID サーバーのインストール方法
1. ガイド付きセットアップの使用 (Guided Setup)
ガイド付きセットアップでは、適切なユーザーアカウントを使用して MID サーバーをインストールし、検証（バリデーション）を行うための一連のタスクが順序立てて提供されます。

2. MID サーバーの手動インストール (Manual Installation)
手動でインストールを行う場合は、以下のステップを実行します：

MID サーバー用ユーザーアカウントの作成：ServiceNow インスタンス側で、MID サーバーが使用する専用アカウントを作成します（適切なロールの割り当てが必要）。

インストーラーファイルのダウンロード：ホスト OS に適したインストーラー（圧縮ファイル）をダウンロードします。

Linux または Windows ホストへの MID サーバーのインストール：ローカルのサーバーまたは仮想マシン上にプログラムを展開し、配置します。

MID サーバーの検証 (Validate)：インスタンス側で MID サーバーを検証し、資格情報（Credentials）へのアクセスが安全に信頼されていることを確認します。

接続性のテスト：MID サーバーと ServiceNow インスタンス、および社内ネットワークの対象機器との間で、正常に通信できるかをテストします。
